# Bazel Codelab

## Before you get started
Take a look at these [informational slides](https://docs.google.com/presentation/d/1Ez8uJv3vdndbMDSNlVu_vK9IaNWP-UfCo2hq3PPM6g4/edit?usp=sharing) to learn about Bazel.

## Start the codelab

Run this script to go to the next stage of the codelab, then read `README.md`:

```bash
./next_exercise.sh
```

### Note
`./next_exercise.sh` **is destructive**:
- it removes any untracked files you created (via `git clean`)
- it reverts any changes to tracked files (via `git reset --hard`)
- ...before checking out the branch for the next exercise.

If you would like to save any work, clone locally and commit before running any scripts.
